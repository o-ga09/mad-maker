# 要求

## 背景

MAD 動画（好きな画像を音楽のビートに合わせて切り替える動画）は、一般的な動画編集ソフトで作ろうとすると、拍の位置を目で探してカットを 1 枚ずつ置く作業になる。曲 1 本で数百カットになり、作るまでの手間が大きい。

## 対象ユーザー

- 手元にある画像（イラスト・写真など）と好きな曲で、手軽に MAD 動画を作りたい人
- 動画編集ソフトの操作や、BPM・拍といった音楽の知識には詳しくない人

## 要求（ユーザーがしたいこと）

| ID | 要求 |
| --- | --- |
| N-01 | 画像と音楽を入れるだけで、ビートに合わせて画像が切り替わる動画を作りたい |
| N-02 | 曲の BPM を知らなくても使いたい。わかっている場合は自分で指定もしたい |
| N-03 | 画像がただ切り替わるだけでなく、ノリの良い動き（フラッシュ・ズーム・シェイクなど）が自動で付いてほしい |
| N-04 | 書き出す前に、仕上がりをその場で確認したい |
| N-05 | 作った動画を、SNS などに投稿できる一般的な形式のファイルとして保存したい |
| N-06 | いずれはインストールせずにブラウザで使いたい |

## やらないこと（MVP のスコープ外）

- タイムラインを手で編集する機能（カットの位置や順番の手動調整）
- 動画素材の取り込み、テキスト・字幕の挿入
- 複数曲の連結、曲の切り出し（トリミング）
- 拍の途中でのテンポ変化への追従（曲全体で BPM は一定とみなす）
- プロジェクトの保存・再読み込み

## 段階

| 段階 | 内容 |
| --- | --- |
| MVP | Go + Ebitengine のデスクトップアプリ。N-01〜N-05 を満たす |
| 次段階 | WebAssembly によるブラウザ版。N-06 を満たす（方針は #11 で決める） |
